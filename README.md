# GeoDev Lab Africa — Bodija Market Road Access Project

## Project question

Which settlements within 5 km of Bodija Market have poor road access to the market?

## Study area

Bodija Market, Ibadan, Oyo State, Nigeria, with a 5 km study-area buffer around the market.

## Project purpose

This project will identify settlements within 5 km of Bodija Market that have relatively poor road access to the market.

## Data sources

- OpenStreetMap: https://www.openstreetmap.org/
- GRID3 Nigeria geospatial data: https://grid3.org/geospatial-data-nigeria
- GRID3 NGA Settlement Extents v4.1: https://data.grid3.org/datasets/GRID3::grid3-nga-settlement-extents-v4-1/about

See `project-brief.md` for the full project brief and data plan.
